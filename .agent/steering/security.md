# Security Steering

- No secrets, private keys, seeds, or reusable signed authorization in git.
- Frontend must not invent canonical financial state.
- Backend must not sign normal user economic transactions.
- Indexer must not become protocol authority.
- Quote/Kuru parameter policy cannot be bypassed by arbitrary creator input.
- Destination-market failure must not lose secured graduation assets.
- External dependencies are version/source pinned where security-relevant.
- Passing tests does not equal unrestricted mainnet safety.
- MAINNET_AUTHORIZED requires explicit human/security authorization.
