# Security Steering

- Frontend must not calculate canonical reserves independently.
- Backend must not sign normal user economic transactions.
- Indexer must not become financial authority.
- Creator input must not bypass quote/Kuru parameter policy.
- Destination-market failure must not lose secured graduation assets.
- No agent may equate successful compilation/tests with unrestricted mainnet safety.
- MAINNET_AUTHORIZED requires explicit human/security authorization.
