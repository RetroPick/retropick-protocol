# @retropick/abi — published V2 ABI catalog

Canonical JSON ABI catalog for the RetroPick V2 launchpad deployed on Monad Testnet
(chain `10143`, deployment block `69509526`, deployed source commit
`f0363249f4b74e58dde37d1241742ca5a92bcfe3`).

## Contents

- `<Contract>.json` — the **complete artifact ABI array** (constructor, functions
  including overloads, events, custom errors) exported from qualified Foundry
  compiler artifacts. Never handwritten fragments.
- `abi.ts` — generated TypeScript barrel exporting every catalog ABI as a `const`
  (single authority: generated from the JSON files, so bundler-resolution consumers
  need no `resolveJsonModule`).
- `manifest.json` — catalog schema v2: per-contract roles, addresses, ownership
  (`RETROPICK_OWNED` / `UPSTREAM_*` / `EXTERNAL_INTERFACE_ONLY`), coverage
  (`FULL_ARTIFACT_ABI` / `QUALIFIED_INTERFACE_ONLY`), source provenance, SHA-256
  hashes and Sourcify verification status.

## Provenance and single-source rule

This catalog is **derived, never hand-edited**, from the frozen deployment bundle
`deployments/monad-testnet/abi/` (itself generated by
`scripts/launchpad/export_deployed_abis.py` from pinned qualified sources — the
deployed Solidity commit and pinned Kuru SDK/contract checkouts). The exporter
revalidates every input SHA-256 before copying, so the catalog cannot drift from
the bundle. `packages/launchpad-sdk/src/abi.ts` is generated from the same bundle,
so SDK, catalog and bundle are consistent by construction.

Regenerate after a bundle refresh:

```bash
python3 scripts/launchpad/export_abi_catalog.py
```

## Ownership labels

- `RETROPICK_OWNED` — RetroPick V2 source at the deployed commit. All 18 deployed
  instances (17 unique contracts + factory-created demo launch) are Sourcify
  `exact_match` verified (runtime) on both
  `https://sourcify-api-monad.blockvision.org/` and `https://sourcify.dev/server/`.
  See `evidence/launchpad/v2-monad-testnet/source-verification-foundry.md`.
- `UPSTREAM_UNISWAP_V4_STACK` (WETH, Permit2, PoolManager, PositionDescriptor,
  PositionManager) — deployment-dependency artifacts from the Uniswap v4
  deployment periphery. Not RetroPick-owned source; not submitted for
  verification by RetroPick.
- `UPSTREAM_KURU` (Router, MarginAccount, OrderBook, KuruAMMVault) — compiled from
  the pinned qualified Kuru contract source. Deployed-bytecode identity is NOT
  established for these (see bundle limitations in `manifest.json`).
- `EXTERNAL_INTERFACE_ONLY` (`ERC20MetadataInterface`) — qualified ERC-20
  interface used for the external Circle USDC proxy; explicitly **not** a
  complete implementation ABI.

Dynamic instances (tokens, curves, liquidity locks created by the factory and
executors at runtime) use the same ABIs as their creating contracts; see the
`templates` section of both manifests.
