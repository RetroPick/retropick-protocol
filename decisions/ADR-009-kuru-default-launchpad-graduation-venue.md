# ADR-009: Kuru as Default V2 Launchpad Graduation Venue

**Status:** PROPOSED  
**Date:** 2026-09-20  
**Scope:** RetroPick Launchpad V2

## Decision proposed

Use Kuru as the default mature secondary-market destination for V2 launches on Monad, while keeping primary bonding economics owned by RetroPick.

## Conditions before acceptance

- current official Kuru contracts/SDK/deployments are pinned;
- market-creation and liquidity requirements are validated;
- graduation failure/retry semantics are proven safe;
- LP-KURU-1 demonstrates a real target-environment market.

Until accepted, this is a target architecture, not proof of deployed integration.
