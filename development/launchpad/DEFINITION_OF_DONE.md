# Definition of Done

A development task is DONE only when:
1. requirement IDs are satisfied;
2. owned paths contain the coherent implementation;
3. forbidden paths were not changed;
4. defined unit/integration/E2E checks pass as applicable;
5. security-relevant failures are covered;
6. generated contracts/API/domain artifacts are updated;
7. evidence is written to the owning evidence lane;
8. downstream handoff artifacts exist;
9. no undocumented blocker remains.

A feature demonstrated through a mocked Kuru, mocked indexer, or mocked contract path is not final integration evidence.
