# Engineering Goal

Ship RetroPick Launchpad V2 from the current Solidity-heavy repository into a production-shaped Monad application supporting creator launch, primary bonding trading, safe graduation into Kuru, and mature secondary trading through:

- real V2 contracts;
- real Kuru integration;
- shared domain/ABI/SDK packages;
- event indexer/read model;
- non-authoritative metadata/search API;
- production web application;
- testing/security qualification;
- CI/CD, observability and deployment evidence.

No mocked external integration is final evidence.

## P0 exclusions

Doorway/cross-chain migration, Prediction, PRISM, arbitrary quote assets, generic multi-venue adapters, RWA issuance and tax/revenue modules are not P0.
