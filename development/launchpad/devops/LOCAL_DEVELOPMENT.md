# Local Development

Target eventual workflow: one workspace install plus one dev command, with explicit Foundry/local-chain/database/indexer/API/web prerequisites.

Do not create Docker complexity unless it simplifies required stateful services. Seed deterministic demo wallets/data for E2E.
