# Observability

Track launch/trade transaction failures, graduation readiness/failure/retry, Kuru failures, indexer lag, RPC errors, API latency/error, web transaction errors and deployment health.

Use structured correlation fields such as requestId, chainId, txHash, launchToken and operation where appropriate.
