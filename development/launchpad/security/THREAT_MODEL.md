# Threat Model

Protect: launch supply, real quote/token reserves, accrued fees, secured graduation assets, role integrity, user signatures and deployment config.

Adversaries: malicious creator/trader/ERC20, MEV/sandwich actor, compromised operator, malicious metadata, failing/changed external venue, RPC/indexer poisoning/staleness, backend abuse and dependency compromise.
