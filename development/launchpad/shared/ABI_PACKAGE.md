# Contract ABI Package

Target package: `packages/contracts`.

Generated from Foundry build artifacts. Contains:
- versioned V2 ABIs;
- typed addresses by environment;
- event/error definitions;
- contract build/source commit metadata.

Do not hand-copy ABI JSON into web/indexer/API apps.
