# Configuration Schema

Machine-readable config eventually owns:
- supported chains;
- contract deployments;
- quote assets;
- Kuru market templates;
- feature flags;
- public RPC/indexer/API/web URLs.

Secrets are never stored here.

Docs explain configuration; they do not duplicate authoritative values.
