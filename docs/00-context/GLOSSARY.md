# Glossary

- **Outcome asset:** ERC-20 claim representing an event outcome.
- **PRISM series:** ERC-20 structured claim backed by an immutable replication basket.
- **Replication vector `x`:** component units required per PRISM share.
- **Payoff matrix `G`:** terminal payoff of each component in each world.
- **Payoff vector `h`:** terminal payoff of one PRISM share, `h = Gx`.
- **Backing `B_i`:** vault units of component `i`.
- **Supply `S`:** outstanding PRISM shares.
- **In-kind redemption:** burn PRISM and receive proportional backing before final settlement.
- **Final settlement:** burn resolved PRISM and receive deterministic settlement value.
- **MATH-1:** gate authorizing production contract design/implementation.
