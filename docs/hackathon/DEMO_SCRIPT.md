# Demo script

Start in the live product, not a terminal. Use testnet assets. Record real receipts and states; never splice a failed transaction into apparent success. A canonical historical market is an honest fallback when live testnet reliability interrupts recording. Say when showing historical evidence.

## 90 seconds

| Time | Screen / narration |
| --- | --- |
| 0–10 | Product landing: “Launching a token is easy. Creating credible liquidity and a mature market is not.” |
| 10–20 | Create token; MON quote, immutable Kuru venue, TESTNET_POLICY_V1. Wallet confirmation. |
| 20–35 | Bonding page; buy, progress and actual reserves. Use prepared funded wallets; no fabricated volume. |
| 35–50 | Final buy / secure; GRADUATING → permissionless completion → real Kuru market. Explain transaction time honestly; cut only idle waits. |
| 50–70 | Kuru balances/orderbook; place small order, fill from second wallet, place/cancel another. Show receipts or canonical proof if recording time is constrained. |
| 70–82 | Launch Proof: immutable venue, market/vault, protected LP/excess lock, observed block. |
| 82–90 | “RetroPick is building the market creation layer for Monad.” |

## Full technical demo — maximum 3 minutes

0:00–0:20: problem and two-stage lifecycle. 0:20–0:50: wallet, create metadata, MON/Kuru policy and launch receipt. 0:50–1:20: curve buy/sell, actual reserve and allocation progress; explain that terminal quote is not assumed equal to a fixed threshold. 1:20–1:50: secure/complete, single Coordinator, fail-and-retry semantics; no need to deliberately fail the live run. 1:50–2:30: Kuru deposit, limit order, second-wallet fill and cancellation; distinguish trading funds from protected custody. 2:30–2:50: Launch Proof and concise architecture. 2:50–3:00: ecosystem value and candid testnet limitations.

## Recording checklist

Use a fresh launch where possible; record token/curve/market/vault/lock and each hash. Prepare two funded testnet actors; avoid exposing keystores, provider secrets or account credentials. Show actual onchain success, not just button clicks. Narrate test trades as functional evidence, not demand. Public video must meet the portal's ≤3-minute limit. Founder pitch is a separate required ≤2-minute video. Keep a canonical market fallback and receipt links available.
