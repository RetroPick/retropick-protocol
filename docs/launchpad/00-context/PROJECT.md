# Project

**Status:** ACTIVE  
**Owner:** Product  
**Purpose:** Define the modern launchpad workstream.

RetroPick Launchpad is an onchain launch lifecycle for ERC-20 assets on Monad. The system combines token creation, bonding-curve price discovery, transparent fee accounting, graduation readiness and a handoff to mature secondary trading.

The hackathon objective is a reliable end-to-end golden path, not maximum product breadth.

Primary actors are creators, traders, liquidity/market infrastructure, and protocol operators. Contract logic owns funds and economics; offchain services improve discovery, metadata and query performance.

Success requires a live creator-to-Kuru flow with transaction evidence, indexed history, browser UX and reproducible tests.
