# Launchpad Research

**Status:** DRAFT  
**Owner:** Research  
**Authority:** Non-authoritative evidence layer

## Purpose

Collect external evidence without allowing competitor implementations or sponsor marketing to redefine RetroPick semantics.

## Requirements

- Record source, retrieval date and uncertainty for material external claims.
- Separate observed behavior from inference and recommendation.
- Route implementation-binding conclusions into an ADR/spec rather than leaving them only in research.

## Non-goals

- Research is not protocol truth.
- Do not copy external API signatures without current verification.

## Acceptance criteria

- Each research file labels verified facts, assumptions and open questions.

## Evidence required

- Source links and dated notes.
