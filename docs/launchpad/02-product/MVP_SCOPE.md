# MVP Scope

**Status:** DRAFT  
**Owner:** Product + Hackathon  
**Authority:** Hackathon P0 scope

## Purpose

Define the minimum complete Metropolis launchpad rather than a broad roadmap.

## Requirements

- P0: create fixed/capped token, bonding buy/sell, launch progress, fees, graduation and Kuru handoff.
- P0 frontend: discover, create, launch detail, wallet transaction flow, activity and post-graduation trading handoff.
- P0 data: contract event indexing and stale-state indicators.
- P1/P2 features are cut before core reliability.

## Non-goals

- No Prediction/PRISM.
- No RWA or tax-module dependency for the golden path.

## Acceptance criteria

- Golden path completes without manual contract calls.
- Every P0 capability has test/evidence ownership.

## Evidence required

- E2E run, deployment addresses, receipts and Kuru market proof.
