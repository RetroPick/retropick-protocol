# Product Taxonomy

**Status:** DRAFT  
**Owner:** Product + Protocol

| Product template | Phase | Onchain primitive | Notes |
|---|---|---|---|
| Meme / cultural | P0 | fixed/capped ERC-20 + bonding | attention/community launch |
| Standard / project | P0 | fixed/capped ERC-20 + bonding | general project token |
| Creator/community | P1 | standard token + policy modules | avoid inventing new primitive unless needed |
| AI/agent | P1 | standard token + agent metadata/modules | AI label alone is not a different ERC-20 |
| Tax/revenue | P2 | standard token + qualified revenue module | bounded/transparent only |
| Registered external asset | P2 | admitted external token | not issued as a generic RetroPick token |
| Direct market | P2 | standard token + direct launch | no bonding phase |

Prediction and PRISM are excluded from this taxonomy lane.

Acceptance: each UI category maps to a real economic primitive and phase; no category silently creates rights not enforced by code/legal structure.
