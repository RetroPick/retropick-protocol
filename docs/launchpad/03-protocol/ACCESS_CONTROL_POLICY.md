# Access Control Policy

**Status:** DRAFT  
**Owner:** Protocol + Security  
**Authority:** Canonical protocol specification

## Purpose

Define every privileged capability.

## Requirements

- Enumerate owner/factory/creator/fee operator/graduation/recovery capabilities.
- Prefer least privilege and explicit two-step ownership where applicable.
- No undocumented privileged path.

## Non-goals

- Does not redefine Prediction/PRISM.

## Acceptance criteria

- Requirements are testable and consistent with PROTOCOL_SPEC.

## Evidence required

- Requirement-to-test traceability.
