# Precision Model

**Status:** DRAFT  
**Owner:** Protocol + Security  
**Authority:** Canonical protocol specification

## Purpose

Define decimals, integer units and rounding.

## Requirements

- Identify units for token, quote, BPS, price and venue precision.
- Specify rounding direction for each calculation.
- Reject unsupported decimal domains rather than guessing.

## Non-goals

- Does not redefine Prediction/PRISM.

## Acceptance criteria

- Requirements are testable and consistent with PROTOCOL_SPEC.

## Evidence required

- Requirement-to-test traceability.
