# Threat Model

**Status:** DRAFT  
**Owner:** Protocol + Security  
**Authority:** Canonical protocol specification

## Purpose

Model adversaries and attack surfaces.

## Requirements

- Include malicious creator, trader/MEV, malicious ERC20, compromised operator, reentrancy/callback, oracle/quote assumptions, venue failure, front-running and denial-of-service.
- Separate protocol safety from market-performance risk.

## Non-goals

- Does not redefine Prediction/PRISM.

## Acceptance criteria

- Requirements are testable and consistent with PROTOCOL_SPEC.

## Evidence required

- Requirement-to-test traceability.
