# Integration Acceptance

**Status:** DRAFT  
**Owner:** Validation + Integrations  
**Authority:** Integration gate

## Purpose

Define what counts as a real integration.

## Requirements

- Pin provider/deployment/API version.
- Demonstrate success and at least one relevant failure/retry path.
- Provide transaction/API evidence from the target environment.
- Show the normal product flow uses the integration without manual hidden steps.

## Non-goals

- SDK import or screenshot alone is not acceptance.

## Acceptance criteria

- P0 integrations have executable evidence.

## Evidence required

- Receipts, market IDs, indexer records, browser E2E and logs.
