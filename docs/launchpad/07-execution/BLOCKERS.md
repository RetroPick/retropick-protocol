# Blockers

**Status:** DRAFT  
**Owner:** Orchestrator  
**Authority:** Execution layer

## Purpose

Maintain only issues that stop a dependency/gate.

## Requirements

- Record blocker, gate impacted, owner, evidence needed and next action.
- Do not hide unresolved external dependency uncertainty.

## Non-goals

- Does not change product/protocol semantics.

## Acceptance criteria

- Current owner/dependency/status is explicit.

## Evidence required

- Task/gate artifacts.
