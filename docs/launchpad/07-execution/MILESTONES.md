# Milestones

**Status:** DRAFT  
**Owner:** Orchestrator  
**Authority:** Execution layer

## Purpose

Turn phase gates into time-boxed deliverables.

## Requirements

- Each milestone has gate, owner, critical path, cut trigger and demoable output.
- Track remaining risk rather than percent-complete optimism.

## Non-goals

- Does not change product/protocol semantics.

## Acceptance criteria

- Current owner/dependency/status is explicit.

## Evidence required

- Task/gate artifacts.
