# Backend Deployment

**Status:** DRAFT  
**Owner:** Release + Operations  
**Authority:** Operational specification

## Purpose

Deploy optional metadata/search/cache services safely.

## Requirements

- Use non-custodial permissions.
- Configure rate limits, database/cache migrations and health checks.
- Rollback independently without changing contract truth.

## Non-goals

- No undocumented privileged workaround.

## Acceptance criteria

- Procedure is reproducible by another operator.

## Evidence required

- Deployment/smoke/monitoring evidence.
