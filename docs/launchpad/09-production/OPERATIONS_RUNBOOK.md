# Operations Runbook

**Status:** DRAFT  
**Owner:** Release + Operations  
**Authority:** Operational specification

## Purpose

Provide executable daily/demo/release procedures.

## Requirements

- Preflight RPC/wallet/balances/contracts/indexer/Kuru/frontend.
- Document graduation retry/recovery observation steps without bypassing access policy.
- Include escalation contacts/roles conceptually, not secrets.

## Non-goals

- No undocumented privileged workaround.

## Acceptance criteria

- Procedure is reproducible by another operator.

## Evidence required

- Deployment/smoke/monitoring evidence.
