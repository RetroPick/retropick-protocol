# Release Checklist

**Status:** DRAFT  
**Owner:** Release + Operations  
**Authority:** Operational specification

## Purpose

Final operational checklist before environment promotion.

## Requirements

- Freeze commit/config, run qualification, verify addresses/roles, sync indexer, deploy app, smoke golden path, verify observability, archive evidence.
- Explicitly record PASS/CONDITIONAL_PASS/FAIL.

## Non-goals

- No undocumented privileged workaround.

## Acceptance criteria

- Procedure is reproducible by another operator.

## Evidence required

- Deployment/smoke/monitoring evidence.
