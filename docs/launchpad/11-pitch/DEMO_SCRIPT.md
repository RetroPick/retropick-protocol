# Demo Script

1. Open RetroPick discover and identify active launches.
2. Create a new token and review quote/supply/fee settings.
3. Sign creation and show the launch address/transaction.
4. Buy from a second wallet; point out price, fees and progress.
5. Sell a portion; show updated balances/activity.
6. Cross the graduation threshold.
7. Show graduation state and transaction.
8. Show the verified Kuru market and post-graduation trading path.
9. Finish on evidence: addresses, transactions, indexed history and tests.

Keep backup deployed assets ready without pretending a backup is the same as a live step.
