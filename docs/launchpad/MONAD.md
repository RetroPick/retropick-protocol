# Monad

Monad is the target chain for Launchpad V2.

Canonical protocol docs do not hardcode mutable RPC/explorer/deployment details. Environment-specific chain IDs/endpoints/addresses belong in machine-readable deployment configuration after verification from official Monad sources.

Required capabilities:
- EVM contract deployment/calls/logs;
- user wallet connectivity;
- stable receipt/event retrieval;
- indexer support;
- Kuru target deployment availability.

No unverified throughput/latency claim is a protocol requirement.
