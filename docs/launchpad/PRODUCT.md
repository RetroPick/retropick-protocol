# Product

## Users

Creators launch assets with explicit token/economic settings. Traders discover launches and trade the primary bonding market. Protocol operators configure bounded templates/quote assets and operate only explicitly privileged lifecycle functions.

## Core promise

A launch has one coherent lifecycle rather than a token generator plus disconnected exchange listing.

Creators get:
- deterministic token deployment;
- transparent supply/economics;
- primary distribution;
- a defined graduation condition;
- a mature Kuru market after successful graduation.

Traders get:
- explicit quote asset;
- deterministic primary pricing;
- fee/slippage visibility;
- observable launch progress/state;
- continued access after graduation.

## Product authority

The browser does not create financial semantics. User-visible supply, reserve, price, fees, progress and graduation state derive from contracts or explicitly derived indexed views.
