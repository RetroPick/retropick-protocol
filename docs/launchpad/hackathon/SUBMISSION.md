# Submission

Before submission re-verify current event/sponsor requirements.

Every technical claim maps to public/live evidence where possible:
repository commit, deployed web app, contract addresses, transaction hashes, indexer/API proof, Kuru market identity and demo recording.

Do not claim production/mainnet readiness from hackathon evidence.
