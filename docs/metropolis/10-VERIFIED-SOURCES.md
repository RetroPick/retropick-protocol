## Source precedence and warnings
Official first-party current docs/code > pinned installed SDK/CLI `--help` and TS types > current RetroPick implementation > research plans > old examples. A verified documentation page is not proof that **the user has credentials**, **a supported quote exists**, or **an onchain transaction succeeded**. Tag every unsupported claim. Do not copy third-party demo API keys, addresses, static sample recipients or development mnemonics into RetroPick.
