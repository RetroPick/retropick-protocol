# Asset Taxonomy

## RETROPICK_PLATFORM

Parent product and shared application/infrastructure layer.

## LAUNCHPAD_CORE

Current ERC20 launch primitive:
- fixed/capped launch token;
- bonding primary market;
- deterministic fees/reserves;
- graduation;
- Kuru mature market.

## PREDICTION_MODULE

Incubating event-linked issuance primitive:
- market definition;
- immutable resolution specification;
- fully collateralized outcome assets;
- resolution/redemption.

## PRISM_MODULE

Incubating structured-outcome primitive:
- admitted component basis;
- exact non-negative replication;
- exact backing;
- mint/redeem;
- partial/final settlement.

## SHARED_PLATFORM_SERVICES

Candidate shared services:
- discovery;
- metadata/search;
- profiles;
- portfolio;
- activity;
- analytics;
- wallet interaction;
- indexer/read model;
- API;
- SDK/types;
- execution-venue connectivity;
- environment/config;
- observability.

Sharing a service never transfers financial authority from contracts to the shared service.
