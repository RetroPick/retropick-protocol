# Module Promotion

A research module becomes a production platform module only through explicit promotion.

## States

~~~text
RESEARCH
-> VALIDATED
-> IMPLEMENTABLE
-> INTEGRATION_CANDIDATE
-> PLATFORM_MODULE
-> STAGING_QUALIFIED
-> PRODUCTION_CANDIDATE
~~~

These are module states, not marketing labels.

## PRISM

PRISM currently remains RESEARCH with MATH-1 active.

Its intended path is:

~~~text
RESEARCH
-> SPEC
-> MATH-1
-> MARKET-THESIS VALIDATION
-> CONTRACT-ARCH-1
-> CONTRACT-1
-> MODULE-ADMISSION-PRISM-1
-> PLATFORM-INTEGRATION-1
-> MODULE-STAGING-1
-> MODULE-PRODUCTION-CANDIDATE
~~~

MODULE-ADMISSION-PRISM-1 means PRISM is technically admissible as a RetroPick platform module. It does not mean mainnet authorization.

A PRISM failure must not block Launchpad Core.
