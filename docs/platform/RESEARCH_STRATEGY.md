# Research Strategy

Research answers questions and produces evidence. It does not silently redefine canonical financial semantics.

## General flow

~~~text
QUESTION
-> CURRENT SOURCE COLLECTION
-> NORMALIZE
-> CLAIM
-> EXPERIMENT / BENCHMARK
-> EVIDENCE
-> ANALYSIS
-> RECOMMENDATION
-> ADR / CANONICAL-DOC PROPOSAL
-> ACCEPTANCE
-> IMPLEMENTATION
-> REVALIDATION
~~~

## Platform research

Focus on shared dependencies, product references, infrastructure, security, reliability, performance and production operations.

## Module research

Financial modules retain specialized research programs.

PRISM uses hypothesis -> formalization -> model -> counterexample search -> exhaustive/adversarial testing -> market simulation -> security analysis -> user/market validation -> gate verdict.
