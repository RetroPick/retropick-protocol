# Hackathon Cut List

When schedule tightens, cut breadth before correctness.

## Never cut

These are protocol-definition or solvency requirements:
- canonical `ResolutionSpec`;
- complete-set collateral conservation;
- `h=Gx` admission semantics;
- runtime `B_i >= S*x_i`;
- back-first mint;
- proportional in-kind redemption;
- immutable activated series definition;
- lifecycle monotonicity;
- `RESOLVED != REDEEMABLE`;
- final settlement funding gate;
- fixed-point/rounding safety;
- core tests and evidence.

If these cannot be completed, reduce the product rather than pretending the protocol is complete.

## Cut first — P2/P3 sponsor extras

- Nansen dashboards;
- strategy-vault polish;
- MetaMask autonomous agent breadth;
- secondary analytics panels;
- multiple external funding routes;
- non-essential visualizations;
- extra RPC providers beyond required resilience.

## Cut second — product breadth

- mobile-specific UI;
- many market templates;
- multiple PRISM series;
- advanced creator forms;
- automatic basket acquisition for retail users;
- generic partial-transformation engine.

Keep one deterministic, explainable PRISM series.

## Cut third — advanced market research

If runtime delivery is at risk, reduce:
- large Monte Carlo campaigns;
- sophisticated market-maker model;
- generalized cost-minimizing replication;
- advanced correlation models.

Do not cut the exact accounting reference model or rounding validation.

## Explicitly deferred regardless of schedule

Unless the canonical plan is changed by ADR:
- Polymarket/Polygon custody;
- custom bridge;
- BackingMirror for same-chain assets;
- arbitrary StatePool/SLE claims;
- approximate replication;
- lending/collateralization of PRISM;
- production legal/compliance claims not independently reviewed.

## Minimum credible submission

If severe time pressure occurs, the irreducible demo is:

```text
1 native fully collateralized binary market
+ split/merge
+ YES/NO Kuru markets
+ deterministic resolution/redeem
+ 1 exact-backed PRISM series
+ PRISM primary mint/redeem
+ PRISM Kuru trade
+ evidence/indexing
```

A narrow system with demonstrable solvency is stronger than a broad sponsor demo with ambiguous financial accounting.
