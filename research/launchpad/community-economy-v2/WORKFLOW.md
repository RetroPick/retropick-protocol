# Iteration workflow

Every iteration follows the research/production/WORKFLOW.md sequence. Create a new numbered manifest in iterations/ and new evidence directory; never replace a prior run. Record question, source retrieval dates/commits, classification, executable hypothesis, commands, exit statuses, artifacts, security findings, decision and next dependency. A proposal is not an accepted ADR.

Use Memorix task context first, capability discovery second, then bounded XERJ current-source and relevant upstream retrieval. Use the discovered grilling and DeFi security skills to challenge each design; use release-evidence and liquidity-accounting rules for qualification and venue interpretation. Do not invoke blockchain tools merely because available; no signing/broadcast capability is needed.

Ownership: experiment contracts/tests and scoped research/evidence only. Canonical v1/v2, original tests, scripts, deployments, apps and other module lanes remain protected. Run baseline.py --check before each commit. Preserve original-test artifact ambiguity as evidence; do not rename production contracts or weaken tests to hide it.

Before economic code, close source/ABI inventory and adversarial accounting specification gates. Before strategies, prove conservation and backing. Before promotion, complete the full invariant/fork/static-analysis campaign and independent review. No source finding or unit test is deployment authority.
