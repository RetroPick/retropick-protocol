# Pons v2 Reference

Retrieved: 2026-09-20
Authority: official docs
Source: https://docs.ponsfamily.com/v2
Classification: VERIFIED_CURRENT_FACT for the cited product description at retrieval time

Observed official product pattern:
- creator launches a token;
- public trades against a bonding curve;
- the launch graduates when the curve completes;
- post-graduation trading moves to a Uniswap v4 pool;
- the flow is non-custodial and wallet-signed;
- graduation is designed to be permissionless/retryable if automatic completion fails;
- product documentation emphasizes explicit reserves, progress, lifecycle transitions and anti-snipe behavior.

RetroPick relevance:
- validates the modern launchpad lifecycle pattern of primary formation -> deterministic graduation -> mature venue;
- useful reference for graduation/failure UX and state visibility;
- does not define RetroPick curve math, fee policy or venue choice.
