# Production Research Gates

These are evidence-generation gates, not release gates.

~~~text
PR-R0 BASELINE
-> PR-R1 DEPENDENCY_QUALIFIED
-> PR-R2 BENCHMARK_SPEC_FROZEN
-> PR-R3 STAGING_MEASURED
-> PR-R4 RESILIENCE_SECURITY_MEASURED
-> PR-R5 CAPACITY_COST_MODELED
-> PR-R6 RESEARCH_VERDICT
~~~

Launchpad Core remains governed by its existing release gates. PRISM remains governed by its research/MATH/module-admission gates.
