# Production Research Workflow

~~~text
QUESTION
-> CURRENT SOURCE COLLECTION
-> NORMALIZE
-> CLAIM
-> EXPERIMENT / BENCHMARK
-> EVIDENCE
-> ANALYSIS
-> RECOMMENDATION
-> ADR / CANONICAL-DOC PROPOSAL
-> ACCEPTANCE
-> IMPLEMENTATION
-> REVALIDATION
~~~

Rules:
- research is informative until accepted;
- distinguish AS-BUILT, TARGET and RESEARCH IDEA;
- measured, simulated and inferred claims remain separate;
- do not invent SLOs before measurement;
- MAINNET_AUTHORIZED requires explicit human authorization.
