# Security Coverage Matrix

## Shared platform

Track wallet/signing, frontend supply chain, backend, indexer, RPC, CI/CD, dependencies, secrets and deployment.

## Launchpad Core

Track reserves, bonding-curve arithmetic, fees, graduation, Kuru handoff, roles/admin, malicious token behavior, invariant/fuzz coverage and deployment integrity.

## PRISM

Track separately under the PRISM program: backing, replication, reservation uniqueness, resolution, settlement and precision.

Shared product infrastructure does not merge module financial threat models.
