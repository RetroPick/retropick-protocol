# Production Research Tooling

Future deterministic tooling may validate:
- JSON/YAML syntax;
- schema conformance;
- unique IDs;
- source freshness metadata;
- benchmark manifests;
- evidence references;
- secret patterns;
- internal links.

Live RPC/Kuru/staging/load benchmarks should run through separate manual/scheduled workflows rather than every pull request.

No tool here is authorized to spend significant real funds automatically.
